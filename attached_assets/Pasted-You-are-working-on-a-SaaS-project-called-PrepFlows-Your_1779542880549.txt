You are working on a SaaS project called “PrepFlows”.

Your task is to redesign the entire UI into a premium Apple / Stripe / Linear level design system.

## 🎯 GOAL
Transform the current UI into a high-end, minimal, premium SaaS interface suitable for a real commercial product.

The product should feel:
- Like Apple website (clean, spacious, premium)
- Like Stripe dashboard (structured, trust-building)
- Like Linear (modern SaaS UI system)

---

## 🎨 DESIGN SYSTEM RULES

### 1. Color System
- Background: #0A0A0A (dark mode default)
- Text: white / #A1A1AA gray
- Accent color: #3B82F6 (blue)
- Borders: white/10 opacity only
- No bright colors except accent

---

### 2. Typography
- Use system font stack or Inter
- Large, thin headings (font-light)
- Clear hierarchy:
  - H1: 48–64px
  - H2: 32–40px
  - Body: 14–16px

---

### 3. Layout Style
- Very large spacing (Apple style)
- Centered content max width: 1100px
- No clutter, reduce UI density
- Use grid layout for sections

---

### 4. Components Style

Buttons:
- Fully rounded (rounded-full)
- Primary: white background + black text
- Secondary: transparent + white border

Cards:
- Background: white/5
- Border: white/10
- Border radius: 16–20px
- Subtle hover scale (1.02)

---

### 5. Animation Rules
- Subtle only
- Fade in on load
- Slight upward motion (10–20px)
- No heavy animations

Use Framer Motion if available.

---
